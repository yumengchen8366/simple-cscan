Simple C-scan · 简单 C-scan

Two entry points, one shared motion/DAQ implementation. 每条代码旁都有英文和中文解释。

Status / 状态: Teaching implementation for the local ATS9462 + NI setup. Offline checks are recorded separately in validation.txt; hardware operation and real PAM imaging are not validated. 本教学实现针对现有 ATS9462 + NI 系统；离线检查见 validation.txt，尚未完成硬件及真实 PAM 验证。

Start here / 从这里开始

p = cscan_settings();
p.runHardware = false;
a = cscan_npt(p);
b = cscan_triggered_streaming(p);

These commands only build and plot timing. They do not synthesize a successful scan or open hardware. 以上命令只生成和绘制时序，不伪造成功扫描，也不打开硬件。

Read: settings → sequence → NPT/TS entry → run_cscan → preview. 先读参数，再读时序，然后入口、扫描流程和预览。

The two versions / 两个版本

English中文
NPT: one 1024-sample record at each planned X position; the default is 200 triggers/s, not the previous free-running 100 kHz experiment.NPT：每个计划 X 位置采 1024 点；默认 200 次触发/秒，不是原来 100 kHz 自由运行测试。
TS: one trigger per row, then continuous CH A samples for the planned row duration. Later DMA boundaries have no optical meaning.TS：每行一个触发，随后连续采 CH A，保留计划整行时间；后面的 DMA 分界没有光学含义。
Both: prepare buffers → preload NI → arm ATS → start NI → read DMA → stop ATS → finish X → save row → X return → Y step.两者：准备缓冲区 → 预载 NI → 启动 ATS 等待 → 启动 NI → 读取 DMA → 停止 ATS → 完成 X → 保存行 → X 回程 → Y 换行。
After all rows, command Y back. Errors stop NI and abort ATS; there is no automatic recovery move because actual position is then uncertain.全部行结束后命令 Y 返回。报错会停止 NI 并中止 ATS；实际位置可能不确定，因此不会自动做故障恢复运动。

Wiring contract — check before hardware / 上机前必须对应的接线

English中文
Table columns 1–5: P0.0 X STEP, P0.1 X DIR, P0.2 Y STEP, P0.3 Y DIR, P0.6 acquisition request. No P0.7 laser output is configured.时序第 1–5 列：P0.0 X STEP、P0.1 X DIR、P0.2 Y STEP、P0.3 Y DIR、P0.6 采集请求。不配置 P0.7 激光输出。
P0.6 must reach ATS TRIG IN through a verified, suitable line driver or externally triggered generator. This is a proposed route, not confirmation of today's BNC wiring. Historical TRIG IN load is about 50 ohms; do not connect the NI digital output directly to that load.P0.6 必须经验证适配的驱动器或外触发发生器送到 ATS TRIG IN。这是本程序要求的路线，不是对当前 BNC 接线的确认。历史 TRIG IN 负载约为 50 欧姆，不能将 NI 数字输出直接接到该负载。
NPT requires exactly one valid ATS trigger for each NI pulse, and the desired signal must arrive inside the short record. A generator must use one output event per request, not an uncontrolled burst. An unrelated free-running laser may be missed.NPT 要求每个 NI 脉冲恰好产生一个有效 ATS 触发，而且目标信号必须落在短记录窗内。发生器每次请求只发一个事件，不能发不受控的脉冲串。与此无时间关系的自由运行激光可能被漏采。
TS requires exactly one controlled row-start trigger and no earlier trigger. CH A then captures continuously; the signal source need not stop between rows. The previous always-on trigger must not remain connected to TRIG IN.TS 要求一个受控行起点触发，且此前不能有其他触发。随后 CH A 连续采样；信号源不必在行间停止。原来的常开触发源不能继续接在 TRIG IN 上。
Route delay/jitter and independent NI/ATS clock drift are not measured here. Coordinates are commanded positions. Check STEP versus the actual TRIG IN edge with a scope, including repeated rows.本程序未测量触发路线延迟/抖动和 NI/ATS 独立时钟漂移。坐标是命令位置。需用示波器比较 STEP 与实际 TRIG IN 边沿，并检查重复行。
For real PAM, establish a laser-derived timing reference and the acoustic arrival window before interpreting the data. TS needs that reference for A-line separation and depth; this code does not silently invent it.真实 PAM 需要先建立与激光有关的时间参考和声信号到达窗口。TS 要用这个参考拆分 A-line 和确定深度；本程序不会凭空假设它。

What the preview means / 预览图代表什么

Each value is max(code)−min(code), converted to volts. NPT uses a short triggered window; TS uses the whole time bin, so its window is much longer and can include many pulses and more noise. Their previews are not quantitatively equivalent. This is a basic amplitude C-scan preview, not an envelope MAP, depth-resolved image, or proof of physical position. 每个值是编码最大值减最小值后换算成伏特。NPT 用短触发窗口；TS 用整个时间分箱，窗口更长，可能包含多个脉冲和更多噪声。因此两幅预览不能直接定量比较；它们不是包络 MAP、深度图或物理位置验证。

Default command: 1 mm/s, 20 X bins × 3 Y rows, X bin 5 µm, Y pitch 1 µm. Trigger starts after 10 motor cycles (=5 µm under the historical calibration). Retained TS row: 0.1 s, 18 million uint16 samples ≈36 MB. NPT row: 20×1024 uint16 samples =40,960 bytes. The X commanded movement is 105 µm; Y accumulated movement is 2 µm. Both return by commanded step counts. 默认参数都是小规模教学设置，并非教授指定的最终扫描参数。

Files and hardware use / 文件与硬件使用

Keep the six .m files in one folder. Run defaults on the Mac. On the laboratory Windows PC, install the NI support package and ATS SDK, close other applications using the cards, verify the route and available travel, then set p.runHardware=true explicitly. The example has no ramps, so it is deliberately limited to ≤4 mm/s and short relative travel. 本示例省去加速段，保留低速小范围限制；不能直接把速度改成原程序的 10 mm/s。

Each hardware run saves plan.mat, row_001.mat etc. (raw ADC codes, preview, row index and Y command), then summary.mat only after the full normal return. Completed row files remain if a later operation fails. 默认离线模式不保存虚拟测量数据。
