# simple-cscan

Simple C-scan teaching code for a photoacoustic microscopy (PAM) setup: NPT and per-row Triggered Streaming acquisition, with English/Chinese explanations for every line.

简单 C-scan 教学代码（光声显微 PAM）：NPT 和每行触发一次的 Triggered Streaming，每行代码都有中英文解释。

Start with `START_HERE_EN_ZH.txt`, then open `Cscan_line_by_line_EN_ZH.html`.
先读 `START_HERE_EN_ZH.txt`，再打开 `Cscan_line_by_line_EN_ZH.html`。

These are teaching files, not bench-validated replacements; see `validation.txt` for what was and was not tested.
这些是教学文件，尚未经过台架验证；测试范围见 `validation.txt`。
